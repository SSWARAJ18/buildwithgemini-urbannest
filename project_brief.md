# My agent: UrbanNest (Apartment & Real Estate Finder)
One-liner: A conversational agent that helps apartment hunters find, compare, and evaluate urban housing listings with a catalog of verified rental and sale properties.

Tool coverage:
- Memory: User's budget, desired neighborhoods, bedroom/bathroom preferences, pet policies (e.g., dog/cat restrictions), commute destination, and move-in timeline.
- Tools: Search property listings by price, location, amenities, and pet policy; schedule apartment tour appointments; query neighborhood safety and transit scores.
- Catalog/UI: Real estate listings catalog rendered as rich A2UI cards (photos, price, specs, address) and side-by-side comparison tables.
- Image gen: Staged interior room visualization (e.g. "modern minimalist living room mockup for a 1-bedroom flat") or exterior architectural rendering.
- Sandbox: Mortgage/rent payment breakdown, total cost of occupancy calculations, and commute transit time estimations.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for financial & commute calculations, Google Maps Places API for neighborhood amenities
